## 👤 About

Personal portfolio website showcasing projects, skills, and background as a Fullstack Developer. Built from scratch with vanilla HTML, CSS, and JavaScript — no frameworks, no dependencies, just clean code.

> *"Building more than software. My passion provides the discipline and focus I need to grow."*

---

## ✨ Features

- **Glow cursor effect** — radial spotlight that follows the mouse in real-time
- **Dark / Light mode** — toggle with smooth theme transition
- **Sticky navbar** — smooth scroll to each section
- **Bento grid layout** — about section with modular cards
- **3D Carousel** — autoplay mindset carousel with progress bar
- **Tag Cloud Sphere** — interactive 3D rotating tech stack via TagCanvas
- **Infinite marquee** — scrolling tech stack strip
- **Contact modal** — "Get in Touch" overlay with book-a-call and email options
- **Fully responsive** — works across screen sizes
